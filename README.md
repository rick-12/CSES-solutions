# CSES Solutions

This repository contains solutions in C++ for the [CSES Problem Set](https://cses.fi/problemset/).

## About

The CSES Problem Set is a curated collection of competitive programming problems covering a wide range of topics, including:

- Dynamic Programming
- Graph Algorithms
- Sorting and Searching
- Tree Algorithms
- Number Theory
- Data Structures
- Mathematics
- Geometry
- Range Queries

This repository is intended to help practice and improve problem-solving skills using C++.

## Repository Structure

Each solution is typically organized in its own file, named according to the problem or topic, making it easy to browse and compile.

## Usage

Compile any C++ file with a standard C++17 compiler:

```bash
g++ solution.cpp -O2 -std=c++17 -o solution
./solution
```

## Goal

To document and share C++ solutions for learning and practice.
